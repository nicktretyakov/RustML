Беговой клуб записывает каждую пробежку в runs.csv: runner, distance_km, minutes и climb_m. Стартовый код считывает один из столбцов с числовыми значениями в column.

    Выведи среднее значение этого столбца для каждого бегуна.
    Затем назови бегуна с наибольшим средним значением, как в последней строке ниже.

Для клуба из двух бегунов и столбца distance_km:

runner
Ana    6.1
Bo     8.4
Name: distance_km, dtype: float64
