Приложение для просмотра потокового видео попросило пользователей поставить оценку от 1 до 10. Некоторые пропустили этот шаг, поэтому в survey.csv есть пустые ячейки с оценками:

Подготовь для команды чистый отчёт:

    Выведи Missing scores: и количество пропусков.
    Удали строки с пропусками, затем выведи Answers kept: и количество оставшихся строк.
    Для оставшихся строк выведи ответы по устройствам, начиная с самых распространённых.
    Выведи таблицу со значениями mean и max оценки для каждой возрастной группы.
