# **Функции активации и нормализации слоёв нейронных сетей**
Активации — набор свободных функций (relu, softmax, …) плюс apply_activation для вектора;
нормализация — ручной LayerNorm по нейронам слоя.

 В policy network они стоят в цепочке Dense → LayerNorm → ReLU, а на выходе действий — Softmax, что даёт нелинейную policy и численно устойчивые вероятности для REINFORCE.

1. Зачем они в сети

В CatPolicyNetwork типичный блок:

Dense (линейный слой)  →  LayerNorm  →  ReLU  →  …

…

Dense (policy)         →  Softmax     →  вероятности действий

Dense (value)          →  (без Softmax) →  скаляр

Dense Wx + b — линейное преобразование

LayerNorm стабилизация масштаба активаций

ReLU нелинейность (иначе вся сеть = одна линейная функция)

Softmax логиты → вероятности policy


2. Функции активации

Все поэлементные, кроме Softmax (по вектору).

ReLU


```
pub fn relu(x: f32) -> f32 {
    if x > 0.0 { x } else { 0.0 }
}
```


ReLU(x) = max(0, x)

Простая, быстрая, стандарт для скрытых слоёв.

Производная: 1 при $x > 0$, иначе 0 (используется в reinforce_step).

Используется в backbone после каждого Dense + LayerNorm.

Leaky ReLU


```
pub fn leaky_relu(x: f32, alpha: f32) -> f32 {
    if x > 0.0 { x } else { alpha * x }
}
```

LeakyReLU(x) = x > 0 или x <=0

Не «убивает» отрицательный градиент полностью.

В текущей сети не подключена к forward (есть как готовая функция).

Sigmoid


```
pub fn sigmoid(x: f32) -> f32 {
    1.0 / (1.0 + (-x).exp())
}
```



Для бинарных выходов / gates.

В policy head не используется (вместо него Softmax на 2 класса).

Tanh


```
pub fn tanh_activation(x: f32) -> f32 {
    x.tanh()
}
```



Готова к использованию; в основном forward пути не стоит.

Softmax (численно устойчивый)


```
pub fn softmax(input: &[f32]) -> Vec<f32> {
    if input.is_empty() { return vec![]; }
    let max_val = *input.iter().max_by(|a, b| a.partial_cmp(b).unwrap()).unwrap();
    let exps: Vec<f32> = input.iter().map(|&x| (x - max_val).exp()).collect();
    let sum_exp: f32 = exps.iter().sum();
    exps.into_iter().map(|e| e / sum_exp).collect()
}
```


Вычитание max_val нет overflow у exp на больших логитах

Деление на сумму сумма вероятностей = 1

На выходе policy [p_feed, p_play]

Это выходная активация policy head, не скрытых слоёв.

3. Layer Normalization


```
pub fn layer_normalization(
    input: &[f32],
    gamma: f32,
    beta: f32,
    epsilon: f32,
) -> Vec<f32> {
    if input.is_empty() { return vec![]; }
    let n = input.len() as f32;
    let mean: f32 = input.iter().sum::<f32>() / n;
    let variance: f32 =
        input.iter().map(|&x| (x - mean).powi(2)).sum::<f32>() / n;
    let std_dev = (variance + epsilon).sqrt();
    input
        .iter()
        .map(|&x| gamma * (x - mean) / std_dev + beta)
        .collect()
}

pub fn layer_norm_default(input: &[f32]) -> Vec<f32> {
    layer_normalization(input, 1.0, 0.0, 1e-5)
}
```

По шагам:

Mean по всем элементам текущего слоя (не по батчу — здесь батч = 1).

Variance (среднее квадратов отклонений).

Std

Нормализация

Аффинное преобразование

По умолчанию «чистая» нормализация без обучаемых scale/shift.
	
Отличие от BatchNorm: статистика по нейронам одного примера, а не по батчу. Для RL с одним state за шаг это естественно.


4. Как это собрано в forward


```
// Backbone
let mut x = self.layer1.forward(&input_state)?;  // Dense
x = layer_norm_default(&x);                      // LayerNorm
x = apply_activation(x, relu);                   // ReLU

for layer in &self.layer_hidden {
    x = layer.forward(&x)?;
    x = layer_norm_default(&x);
    x = apply_activation(x, relu);
}

// Policy head
let logits = self.layer2_policy.forward(&x)?;
let policy = softmax(&logits);                   // Softmax

// Value head — без Softmax
let value = self.layer_value.forward(&x)?[0];
```

	
Порядок Linear → Norm → Activation — распространённый вариант (есть и Activation → Norm).

Для архитектур с несколькими hidden (DeepMLP и т.д.) тот же блок повторяется для каждого layer_hidden.


5. Связь с обратным проходом (REINFORCE)

В reinforce_step для ReLU учитывается субградиент:

```
if h_act[j] <= 0.0 {

```
