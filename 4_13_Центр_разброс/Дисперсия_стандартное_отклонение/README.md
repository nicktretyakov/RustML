Контроль качества проверяет, насколько равномерно машина наполняет бутылки соком. В стартовом коде считываются шесть значений объёма в мл и выводится то, что возвращает spread_by_hand(a), рядом с np.std. Заверши эту функцию так, чтобы она возвращала:

    дисперсию: среднее значение квадратов отклонений от среднего значения a,
    стандартное отклонение — квадратный корень из дисперсии.
printf "1004\n996\n1011\n993\n1002\n998\n" | ./target/release/quality_control
