Два кинотеатра могут объединить свои таблицы продаж билетов, только если их структура совпадает. Билеты Park находятся в rows; билеты Plaza — в plaza.

    Преобразуй rows в массив park.
    Выведи количество дней, сеансов и значений для каждого кинотеатра, сначала Park.
    Выведи Same layout: и True или False.
cargo run < input.txt

Для 2 дней по 3 сеанса (48, 112, 65, затем 37, 98, 120):

Park: 2 days, 3 showings a day, 6 values
Plaza: 7 days, 4 showings a day, 28 values
Same layout: False
