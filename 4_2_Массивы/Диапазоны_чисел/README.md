Тренер по бегу расставляет конусы. Программа считывает позиции первого и последнего конусов (м), расстояние между ними и количество пунктов с водой. Выведите:

    Cones: от первого до последнего с заданным шагом (np.arange).
    Stations: равномерно распределённые точки, включая первый и последний конусы (np.linspace).
    Times: ноль для каждого конуса — для времени бегунов (np.zeros).

Для 0, 40, 10 и 3:

Cones: [ 0 10 20 30 40]
Stations: [ 0. 20. 40.]
Times: [0. 0. 0. 0. 0.]
