В пункте проката каяков подсчитывают количество каяков, арендованных с понедельника по среду. Программа считывает эти три значения, а затем прогноз на четверг — десятичное число.

    Создай массив rented из трёх значений и выведи его.
    Создай массив week из трёх значений и прогноза, именно в таком порядке, и выведи его.
    Выведи тип week.
echo -e "5\n4\n6\n7.5" | cargo run

[ 8 15  4]
