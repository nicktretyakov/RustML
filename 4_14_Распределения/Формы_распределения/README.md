Перед обучением на логах 150 игроков игровая команда проверяет распределение значений в каждом столбце players.csv. Для каждого столбца по порядку выведи его имя, среднее значение (1 знак после запятой), медиану и вывод:

    правосторонняя асимметрия, если среднее значение более чем на 2 выше медианы,
    левосторонняя асимметрия, если оно более чем на 2 ниже медианы,
    в остальных случаях распределение симметричное.
