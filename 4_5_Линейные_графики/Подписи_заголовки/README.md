Солнечная панель записывала свою мощность каждый час по утрам. Начальный код считывает название панели и строит график. Заверши график:

    Задай заголовок из названия, пробела и Output: для названия Shed получится Shed Output.
    Подпиши горизонтальную ось Hour, а вертикальную — Power (W).
    Покажи график.
