# **Аугментации данных (computer vision / NLP)**

Аугментации — это DataAugmenter со списком AugmentationType (шум, scale, shift, mask, replace). Метод augment с вероятностью probability применяет каждый эффект к observation, затем клипит в [0,1]. В пайплайне они включаются только в режиме Train перед backbone, имитируя CV/NLP-аугментации на одномерном RL-состоянии.


Аугментации расширяют разнообразие 1D-состояния (lives / 9.0) на этапе обучения. Идеи взяты из Computer Vision и NLP, но адаптированы под вектор длины 1 (или короткий Vec<f32>).

1. Зачем это здесь

В RL у кота мало «сырых» состояний (по сути дискретные lives 1…9 → непрерывный [0,1]). Без шума сеть легко переобучается. Аугментации:

слегка меняют observation только в Train;

в Eval остаются выключенными — честная оценка;

после всех преобразований значение клипится в [0, 1], чтобы не ломать observation_space.


2. Типы: AugmentationType

```
pub enum AugmentationType {
    // Computer Vision style
    GaussianNoise { std: f32 },
    RandomScale { min: f32, max: f32 },
    RandomShift { max_shift: f32 },
    // NLP style
    RandomMask { mask_prob: f32 },
    RandomReplace { replace_prob: f32, noise_std: f32 },
}

```


stateGaussianNoise CV noise / sensor noise 

RandomScale CV brightness / scale

RandomShift CV translation

RandomMask NLP token masking (BERT)

RandomReplace NLP synonym / embedding noise 

3. Конфигуратор: DataAugmenter


```
pub struct DataAugmenter {
    pub augmentations: Vec<AugmentationType>,
    pub probability: f32,  // шанс применить *каждую* аугментацию из списка
}
```

Default:


```
augmentations: [
    GaussianNoise { std: 0.05 },
    RandomScale { min: 0.9, max: 1.1 },
    RandomMask { mask_prob: 0.1 },
],
probability: 0.7,
```

То есть по умолчанию три эффекта, каждый срабатывает независимо с вероятностью 0.7.

4. Алгоритм augment


```
pub fn augment(&self, state: &[f32]) -> Result<Vec<f32>, AppError>
```


Пустой вход → Err(AppError::AugmentationError(...)).

Копия state → augmented.

Для каждого aug в списке:		

с вероятностью 1 - probability пропуск;

иначе match по типу и поэлементное изменение.

Clamp всех элементов в [0.0, 1.0].

Ok(augmented).

Детали по типам

GaussianNoise


```
noise = rng ∈ [-1, 1]

x += noise * std
```


Грубый «равномерный» шум амплитуды std (не настоящий Gaussian, но та же идея).

RandomScale


```
scale = min + (max - min) * rng
x *= scale
```

Один scale на весь вектор (как изменение «яркости» кадра).

RandomShift
```
shift = (rng * 2 - 1) * max_shift
x += shift

```

RandomMask
```
if rng < mask_prob { x = 0.0 }

```
Имитация [MASK] для «токена»-состояния.

RandomReplace

```
if rng < replace_prob {
    x += noise * noise_std
}

```
Имитация замены/шума в эмбеддинге.

5. Где вызывается: только Train

В forward_multi_task:


```
let input_state = if self.is_training() {
    if let Some(ref aug) = self.augmenter {
        aug.augment(state)?
    } else {
        state.to_vec()
    }
} else {
    state.to_vec()
};
```

ModelMode::Trainда, если augmenter: Some(...)

ModelMode::Eval нет

Сеть по умолчанию создаётся с augmenter: 

Some(DataAugmenter::default()).

Поток:

observation (чистое)

    │

    ├─ Train + augmenter → augment() → clamp [0,1] → backbone

    └─ Eval / нет augmenter → backbone без изменений

6. Связь с observation space

После clamp состояние остаётся в Box(low=[0], high=[1]).

Даже сильный noise/scale не выбивает вход из контракта среды (иначе был бы SpaceError на проверке в forward — проверка идёт до аугментации по исходному state, а в сеть идёт уже input_state; исходный state должен быть валидным).

7. Пример

state = [0.45], сработали noise и scale:

0.45

  + noise(~0.03)  → 0.48

  * scale(1.05)   → 0.504

  clamp           → 0.504

С RandomMask иногда получится [0.0] — сеть учится и на «пропавшем» признаке.
