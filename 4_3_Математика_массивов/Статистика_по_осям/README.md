В спортзале подсчитывали число посетителей в течение четырёх недель. В visits каждая строка соответствует неделе, а каждый столбец — дню недели, названия которых указаны в days. Выведите:

    Per weekday: среднее значение для каждого дня недели.
    Per week: среднее значение для каждой недели.
    Busiest day: название дня недели с наибольшим средним значением.

Округлите средние значения до 2 знаков после запятой. Для спортзала с данными за две недели:

Per weekday: [42.  51.  46.  63.5 70.5]
Per week: [53.6 55.6]
Busiest day: Fri
