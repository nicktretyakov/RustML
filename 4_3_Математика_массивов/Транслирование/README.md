Фитнес-приложение центрирует каждую таблицу перед тренировкой. В начальном коде вызывается center для двух таблиц: users (3 признака) и workouts (2), а затем выводятся результаты. Сейчас center возвращает таблицу без изменений.

Дополните center, чтобы она вычитала среднее значение каждого столбца из этого столбца независимо от количества столбцов. Оставьте строки ниже без изменений.

Для двух пользователей и двух тренировок вывод будет выглядеть так:

Centered users:
[[-6.  7. -5.]
 [ 6. -7.  5.]]
Column means after centering: [0. 0. 0.]
Centered workouts:
[[-10. -90.]
 [ 10.  90.]]
Column means after centering: [0. 0.]
