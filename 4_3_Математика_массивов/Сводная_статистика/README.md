Две библиотеки, шесть дней. Программа считывает количество книг в главной библиотеке в books; данные филиала в деревне находятся в village. Выведите:

    Busier: филиал (main или village) с большим средним значением и это среднее значение.
    Steadier: филиал с меньшим std и это значение std.
    Best single day: наибольшее количество книг в любой из библиотек.

Округляйте с помощью np.round(x, 2). Для значений главной библиотеки 55, 58, 53, 60, 57, 56:

Busier: main, 56.5 books a day
Steadier: main, std 2.22
Best single day: 60
