**2. Выбор вида LLM**
Encoder-only

Особенность: содержат только блоки энкодера.
Представители: BERT, RoBERTa, DistilBERT.
Задачи: классификация текста, NER, вопросно-ответные задачи.
Важно: BERT — не типичная модель для машинного перевода; перевод обычно решается encoder-decoder моделями.

Особенность: содержат только блоки декодера.
Представители: серия GPT.
Задачи: генерация текста, авторегрессионное предсказание следующего токена.
Encoder-Decoder

Особенность: содержат и энкодер, и декодер.
Представители: BART, T5.
Задачи: машинный перевод, суммаризация.

**4. Выбор реализации эмбеддингов**

Текстовые эмбеддинги

Это самый обширный класс, который делится по уровню гранулярности и методу создания.

По уровню гранулярности:

    Символьные (Character-level): Каждый символ (буква, знак препинания) представлен отдельным вектором. Используется в моделях вроде CharCNN для генерации представлений слов.

    Подсловные (Subword-level): Слова разбиваются на часто встречающиеся части (подслова). Это позволяет эффективно представлять редкие и неизвестные слова. Популярные алгоритмы: Byte-Pair Encoding (BPE), WordPiece (используется в BERT), SentencePiece.

    Словесные (Word-level): Каждому слову в словаре соответствует один вектор. Классические примеры: Word2Vec, GloVe, FastText.

    Предложений (Sentence-level): Весь текст предложения преобразуется в один вектор. Примеры моделей: Sentence-BERT (SBERT), Universal Sentence Encoder (USE), InferSent.

    Документов (Document-level): Представление целого документа (статьи, книги). Методы: Doc2Vec, усреднение словесных эмбеддингов, дообученный BERT.

По методу обучения:

    Частотные (Frequency-based): Основаны на подсчете встречаемости слов. Примеры: Bag-of-Words (BoW), TF-IDF, Latent Semantic Analysis (LSA).

    Статические (Static): Каждому слову присваивается один фиксированный вектор, независимо от контекста. Примеры: Word2Vec (CBOW, Skip-gram), GloVe, FastText.

    Контекстные (Contextual): Вектор слова зависит от его окружения в предложении. Это современный стандарт. Примеры: BERT, ELMo, GPT, Transformer-XL, XLNet.

Специализированные текстовые эмбеддинги:

    Эмбеддинги кода: Представляют программный код, захватывая его синтаксис и семантику. Примеры моделей: CodeBERT, GraphCodeBERT (использует графы потоков данных).

    Эмбеддинги табличных данных: Представляют строки и столбцы таблиц. Примеры моделей: TURL, TaBERT, TabTransformer.

    Эмбеддинги онтологий: Представляют концепции и отношения в графах знаний. Методы: Onto2Vec, OPA2Vec, RDF2vec.

Эмбеддинги изображений

Преобразуют пиксели изображения в вектор, описывающий его визуальное содержание.

    На основе сверточных сетей (CNN): Используют предобученные модели для извлечения признаков. Классический пример — семейство ResNet (ResNet-50, ResNet-101), где вектор из предпоследнего слоя используется как эмбеддинг.

    На основе трансформеров (ViT): Vision Transformer (ViT) разбивает изображение на патчи и применяет к ним механизм внимания, показывая отличные результаты на больших данных.

    Мультимодальные (CLIP): Модель CLIP от OpenAI обучена на парах «изображение-текст». Она создает общее пространство эмбеддингов, позволяя искать изображения по текстовому описанию и наоборот.

Аудиоэмбеддинги

Представляют звук (речь, музыку, звуки) в виде векторов.

    На основе самообучения (Self-supervised): Современные модели, предобученные на большом объеме аудио без разметки. Примеры: Wav2Vec 2.0, HuBERT, WavLM. Они показали высокую эффективность для задач распознавания речи.

    Speech2Vec: Аналог Word2Vec для аудио, где модель учится предсказывать соседние аудиофрагменты.

    Мультимодальные (CLAP): Модель CLAP (Contrastive Language–Audio Pre-Training) выравнивает аудио и текст в общем пространстве, подобно CLIP для изображений.

Эмбеддинги графов

Представляют узлы, ребра или целые графы (например, социальные сети, молекулы) в виде векторов.

    По объекту:

        Узлов (Node): Вектор для каждого узла графа.

        Ребер (Edge): Вектор для каждого ребра, описывающий его тип или свойства.

        Подграфов (Subgraph): Вектор для части графа, например, сообщества.

        Всего графа (Whole Graph): Один вектор для всего графа.

    По методу:

        Матричная факторизация: Разложение матрицы смежности графа.

        Случайные блуждания (Random Walks): Генерация последовательностей узлов (например, DeepWalk, node2vec).

        Глубокое обучение (Deep Learning): Использование графовых нейронных сетей (GNN).

Эмбеддинги для рекомендательных систем

Представляют пользователей и товары в виде векторов для предсказания предпочтений.

    Коллаборативная фильтрация (Collaborative Filtering): Векторы пользователей и товаров обучаются на основе истории взаимодействий (клики, покупки, оценки).

    Контентные (Content-based): Используют текстовые и другие признаки товара (например, эмбеддинги BERT для описания) для построения его вектора.

    На основе графов (Graph-based): Моделируют взаимодействия пользователей и товаров как граф, используя методы вроде DeepWalk или Node2vec для получения эмбеддингов.

Другие типы и общие классификации

    Мультимодальные эмбеддинги: Представляют разные типы данных (текст, изображение, аудио) в едином векторном пространстве. Пример — CLIP. По способу объединения данных делятся на Early Fusion, Mid Fusion и Late Fusion.

    Разреженные (Sparse) vs. Плотные (Dense):

        Разреженные: Векторы большой размерности, где большинство элементов равны нулю (например, TF-IDF, BM25). Хороши для точного поиска по ключевым словам.

        Плотные: Векторы небольшой размерности (обычно 384–3072), где все элементы значимы. Лучше улавливают семантику.

    Мультивекторные (Multi-vector): Вместо одного вектора на текст используется несколько векторов (например, один на каждый токен), как в модели ColBERT. Это обеспечивает более точное взаимодействие при поиске.

    Эмбеддинги на основе LLM: Большие языковые модели (LLM) все чаще используются для генерации высококачественных эмбеддингов. Они могут быть инструктивно-настроенными (instruction-tuned) для конкретных задач.

Позиционные эмбеддинги — это аналог эмбеддингов токенов. Отличаются они тем, что кодируют не смысл токенов, а «смысл позиции». Всё дело в том, что архитектура трансформера сама по себе не умеет учитывать позицию слов, поскольку все они обрабатываются одновременно и параллельно. Нужен способ передать в модель информацию о порядке слов. Для этого и используются позиционные эмбеддинги: они позволяют модели улавливать последовательные отношения, такие как структура предложения, порядок и зависимости.

Эмбеддинги токенов преобразуют токены в числовые векторы, которые сохраняют семантическую информацию о тексте. Позиционные эмбеддинги добавляют информацию о порядке токенов, потому что self-attention сам по себе не различает порядок — он перестановочно-инвариантен.

Эмбеддинги — не единственный способ закодировать позиции. Например,  авторы используют синусоидальное позиционное кодирование. В этом случае векторы всех позиций не обучаются, а вычисляются заранее на основе функций sin и cos. Ещё есть позиционное кодирование на основе частот (например, с использованием вейвлет-преобразований), а также некоторые другие методы.

Технически позиционные эмбеддинги представляют собой матрицу размером max_seq_len × emb_size, где:

    max_seq_len — максимальный размер контекста (количество токенов), который можно подать на вход модели. Меньше — можно, больше — нельзя. LLM либо обрежет излишки до максимально разрешённого размера, либо завершится с ошибкой.

    emb_size — размерность эмбеддинга. Означает то же самое, что и для эмбеддингов токенов, и обязательно должен быть ей равен.

Оба этих параметра задаются перед началом обучения модели.

Каждая ячейка матрицы эмбеддинга содержит число с плавающей точкой (float). Каждая строка содержит вектор, кодирующий соответствующую позицию. Так же как и для токенов, матрица позиционных эмбеддингов сначала инициализируется случайными числами. Затем во время обучения они меняются, чтобы лучше «представлять» соответствующую позицию.

**6. Выбор Masked Multi-Head Attention**

Под «Masked Multi-Head Attention» (MMHA) обычно понимается Multi-Head Attention (MHA), в которой к матрице attention-скоров применяется маска, запрещающая обращение к определённым позициям. Чаще всего это каузальная (causal) маска, маска может быть любой — блочной, локальной, разреженной, обучаемой.

6.1. По типу маски (паттерну запретов)

Стандартные маски

    Causal / Future mask (look-ahead mask) — классическая верхнетреугольная маска: токен ii может смотреть только на позиции j≤ij≤i. Это базовая реализация MMHA в декодере Transformer.

    Strict causal mask — запрещает даже обращение к самому себе (j<ij<i, не j≤ij≤i).

    Padding mask — маскирует padding-токены, чтобы они не влияли на attention.

    Combined mask — совместное применение padding-маски и causal-маски (стандарт в decoder-only моделях).

Локальные и оконные маски

    Sliding window causal mask — causal-маска, ограниченная окном: токен видит только последние ww позиций плюс, возможно, «sink-токены» в начале.

    Block causal mask — последовательность разбивается на блоки (например, по EOS-токену), внутри блока causal-маска применяется отдельно.

    Chunked causal mask — causal-маска, применяемая к чанкам фиксированного размера.

    Local + global sparse mask — комбинация локального окна и нескольких глобальных токенов, которые видят всю последовательность.

Разреженные и структурированные маски

    Banded mask — attention ограничен диагональной полосой вокруг текущей позиции.

    Dilated / strided mask — attention с пропусками (аналог дилатированных свёрток), позволяющий увеличить рецептивное поле без роста сложности.

    Block-diagonal mask — attention разрешён только внутри блоков, между блоками — запрещён.

    Slash attention mask — токены attend к фиксированному позиционному смещению (структурный паттерн, встречающийся в обученных моделях).

Специализированные маски

    Frame-wise block mask — для мультимодальных/видео-задач: маскирование на уровне кадров.

    Frame-wise block causal mask — комбинация frame-wise маски с causal-ограничением.

    Full visual mask — в мультимодальных моделях: визуальные токены могут видеть друг друга полностью, а текстовые — causal.

    Future-aware masks (компрессированные) — для vision-language inference: позволяют визуальным токенам «оглядываться» на последующие текстовые вопросы, что улучшает мультимодальное рассуждение.

    Segment-based bidirectional mask (MAS) — в prefill-фазе GPT токены внутри одного сегмента видят друг друга двунаправленно, а генерация сохраняет causal-маску.

    Relaxed causal mask — позволяет attention к нескольким предыдущим шагам, увеличивая рецептивное поле.

    Modality-mutual attention mask — модификация causal-маски в MLLM: «вырезание дыры», чтобы предшествующие image-токены могли post-hoc attend к последующим текстовым токенам.

Обучемые и адаптивные маски

    Learnable mask — маска, параметры которой обучаются вместе с моделью.

    Selective attention mask — обучаемая маска, фильтрующая нерелевантные признаки (spatial, temporal, channel, semantic).

    Gated mask / learnable decay mask — маска с обучаемым коэффициентом затухания.

    Attention head masking — выборочное «выключение» отдельных голов внимания на инференсе для управления поведением модели.

6.2. По механизму применения маски

    Additive mask (аддитивная) — к attention-скорам до softmax добавляется матрица MM с 00 и −∞−∞. Стандарт в оригинальном Transformer.

    Multiplicative mask (мультипликативная) — attention-скоры поэлементно умножаются на бинарную маску (0/1).

    Boolean mask — маска задаётся булевым тензором, где True означает «запрещено» (так работает, например, attn_mask в PyTorch).

    Mask as bias — маска передаётся как bias-тензор, который складывается с логитами (современный подход в PyTorch SDPA и FlashAttention).

6.3. По архитектурным вариантам Multi-Head Attention

Маска может применяться к любому варианту MHA, порождая соответствующие MMHA-реализации.

    Vanilla MHA + mask — классический вариант: HH голов, каждая со своим Q,K,VQ,K,V.

    Multi-Query Attention (MQA) + mask — все головы запросов разделяют одну пару K,VK,V.

    Grouped-Query Attention (GQA) + mask — промежуточный вариант: несколько голов запросов на одну группу K,VK,V.

    Multi-Head Latent Attention (MLA) + mask — сжатие K,VK,V в латентное пространство (DeepSeek-V2/V3), с masked-MHA prefill-путём.

    Sparse MLA + mask — разреженная версия MLA с masked-MHA prefill.

    BiTransformer masked co-attentive MHA — маскированное ко-внимание над двумя последовательностями одновременно.

    Synthesizer + causal mask — альтернатива dot-product attention, где attention-веса синтезируются, а не вычисляются через QKTQKT, с causal-маской.

6.4. По аппаратно-ориентированным реализациям

    PyTorch MultiheadAttention с attn_mask — стандартная реализация, где маска передаётся как параметр.

    xFormers MultiHeadDispatch с маской — оптимизированная реализация.

    Ручная реализация MHA с маской — explicit matmul + mask + softmax.

    FlashAttention (v1/v2/v3) с causal mask — IO-aware точный attention, поддерживающий causal-маску и произвольные маски.

    PagedAttention с маской — attention с управлением KV-cache страницами (vLLM), поддерживает masked-MHA prefill.

    Fused masked multi-head attention — оператор, объединяющий mask + MHA в один GPU-ядерный вызов (например, в PaddlePaddle).

    TensorRT-LLM MHA/MQA/GQA с маской — оптимизированные реализации для авторегрессионного инференса.

6.5. По уровню применения маски

    Token-level mask — маска на уровне отдельных токенов (causal, padding).

    Head-level mask — маска на уровне голов внимания (head masking для управления функциональностью).

    Layer-level mask — маска на уровне слоёв (например, отключение attention в определённых слоях).

    Sequence-level mask — маска на уровне целых последовательностей (например, в батче).

    Modality-level mask — маска на уровне модальностей (текст vs изображение vs аудио).

6.6. По режиму использования

    Training mask — causal-маска для параллельного обучения авторегрессионных моделей (teacher forcing).

    Inference mask — causal-маска в сочетании с KV-cache для пошаговой генерации.

    Prefill mask — masked-MHA prefill-фаза (обработка всего промпта сразу).

    Decode mask — маска для генерации по одному токену с KV-cache.

    Non-autoregressive mask — маски для NAR-декодеров (например, block-based attention mask).

6.7. По фреймворкам и библиотекам

    PyTorch — nn.MultiheadAttention(attn_mask=...), scaled_dot_product_attention(attn_mask=...).

    TensorFlow/Keras — MultiHeadAttention(attention_mask=...).

    JAX/Flax — nn.attention.dot_product_attention(mask=...).

    xFormers — memory_efficient_attention с поддержкой масок.

    PaddlePaddle — masked_multihead_attention (fused GPU-оператор).

    TensorRT-LLM — MHA/MQA/GQA с масками для инференса.

    vLLM — PagedAttention + masked-MHA prefill.

    HuggingFace Transformers — различные реализации attention с масками в моделях (GPT, LLaMA, T5, BART и др.).

6.8. Нестандартные и исследовательские варианты

    Random mask — случайное маскирование позиций (для регуляризации или MAE-подобных задач).

    Attention-map-based mask — маска строится на основе карты внимания (self-guided masked autoencoders).

    Clustering-based mask — маскирование на основе кластеризации attention-паттернов.

    Iterative refinement mask — итеративное обновление маски в процессе генерации (для подавления галлюцинаций в VLM).

    Graph masked attention — маска на основе структуры графа (для GNN-Transformer гибридов).

    Differential equation-based mask — маска, задаваемая через дифференциальные уравнения на графах (теоретический фреймворк для масштабируемых masked Transformer).



 
**7. Оценки внимания**

Под «оценкой внимания» (attention evaluation) в машинном обучении понимают два принципиально разных процесса: вычисление весов внимания (как модель распределяет фокус) и оценку/интерпретацию этих весов (что они означают и насколько хороши). Ниже — полная классификация по обеим осям.

7.1. Функции оценки (Scoring Functions) — как вычисляются веса внимания

Это ядро механизма: функция, которая по запросу qq и ключу kk выдаёт скалярную оценку релевантности.
Базовые семейства

    Аддитивная (Additive / Bahdanau attention).

    Мультипликативная (Dot-product).

    Масштабированная мультипликативная (Scaled dot-product).
    ​
    Билинейная (Bilinear / General).

Дополнительные семейства

    На основе расстояния (Distance-based).

    Косинусная (Cosine).

    Location-based.

    Concat (конкатенация).

Активации и нормализации поверх оценок

    Softmax: стандартная нормализация оценок в вероятностное распределение.

    Sigmoid: альтернативная активация, дающая независимые «вероятности» для каждого ключа.

    Tanh: используется внутри аддитивной функции.

    Linear (без активации): сохраняет «сырые» оценки, распределение ближе к гауссову.

    Sparsemax: разреженная альтернатива softmax, обнуляющая нерелевантные веса.

    Entmax: обобщение softmax и sparsemax с настраиваемой разреженностью.

7.2. Методы нормализации и взвешивания

    Softmax normalization — классический подход: веса положительны и суммируются в 1.

    Entropy-based regularization — добавление энтропийного штрафа к распределению внимания для контроля его «остроты».

    Temperature scaling — деление оценок на температуру TT до softmax для управления концентрацией распределения.

    Gumbel-Softmax — репараметризуемая выборка для дискретного внимания.

7.3. Вычислительные реализации (как именно считается внимание)

    Vanilla dot-product attention — прямое вычисление QKTQKT, затем softmax, затем умножение на VV.

    Ручная реализация MHA — explicit matmul + маска + softmax + взвешенная сумма.

    FlashAttention (v1/v2/v3) — IO-aware точный attention, минимизирующий чтение/запись в память.

    PagedAttention — attention с управлением KV-cache страницами (vLLM).

    Memory-efficient attention (xFormers) — оптимизированные ядра для GPU.

    Fused attention — объединение нескольких операций в одно GPU-ядро (например, в PaddlePaddle).

    Sparse attention — вычисление attention только по разреженному паттерну (Longformer, BigBird).

    Linear attention — аппроксимация attention с линейной сложностью (Performer, Linformer).

    Kernel-based attention — attention как ядерный метод (например, через RBF-ядро).

7.4. Методы оценки и интерпретации весов внимания

Это вторая ось: как мы анализируем и валидируем то, что модель «сфокусировалась».
Визуализация

    Attention heatmap — тепловая карта весов внимания (по слоям, головам, токенам).

    Per-head overlay maps — наложение карт разных голов для выявления паттернов.

    Dynamic Accumulated Attention Map (DAAM) — визуализация эволюции attention во времени в ViT.

    Attention flow mapping — визуализация потока внимания от конкретных query-позиций.

    Pattern-lens — инструмент для фильтрации и выбора паттернов по модели, слою, голове, промпту.

Атрибуционные методы

    Attention Rollout — перемножение матриц внимания последовательных слоёв для получения единого оператора влияния. Позволяет увидеть, как информация распространяется по глубине сети.

    Attention Flow — альтернативный подход, рассматривающий внимание как пропорциональные факторы на каждом шаге. Менее строгий, чем rollout.

    Gradient-weighted Rollout — усовершенствование rollout с весами, учитывающими градиенты (Chefer et al., 2021).

    ValueZeroing — метод атрибуции, обнуляющий value-векторы для оценки вклада.

    ALTI — метод извлечения attention-скоров для интерпретации.

Метрики оценки качества внимания

    Self-Attention Focus — метрика, quantifying, насколько токен фокусируется на себе (диагональные элементы attention-матрицы).

    Self-Attention Vector Output Similarities — косинусное сходство выходных векторов внимания для оценки специализации голов.

    KL-дивергенция и косинусное сходство — для сравнения attention-карт между слоями/моделями.

    MRR (Mean Reciprocal Rank) и nDCG@k — для оценки ранжирования в cross-attention сценариях.

    Entropy-matched null baseline — сравнение спектрального сигнала attention с нулевым baseline для валидации структуры.

Метрики для saliency / visual attention

    AUC (Area Under Curve) — площадь под ROC-кривой для предсказания фиксаций.

    CC (Pearson's Correlation Coefficient) — корреляция предсказанной карты внимания с ground truth.

    SIM (Similarity) — сходство распределений.

    KLD (Kullback-Leibler Divergence) — divergence между предсказанным и истинным распределением.

    NSS (Normalized Scanpath Saliency) — нормализованная saliency для фиксаций.

    IG (Information Gain) — информационный выигрыш.

    sAUC (shuffled AUC) — AUC с перемешанными негативами для контроля bias.

7.5. Архитектурные вариации оценки внимания

    Self-attention — Q,K,VQ,K,V из одной последовательности.

    Cross-attention — QQ из одной модальности/последовательности, K,VK,V — из другой.

    Multi-Head Attention (MHA) — параллельное вычисление attention в нескольких подпространствах.

    Multi-Query Attention (MQA) — все головы разделяют одну пару K,VK,V.

    Grouped-Query Attention (GQA) — промежуточный вариант между MHA и MQA.

    Multi-Head Latent Attention (MLA) — сжатие K,VK,V в латентное пространство (DeepSeek).

    Causal Attention with Lookahead Keys — causal-маска с дополнительными lookahead-ключами.

    Two-step attention-weighted sum — двухэтапное взвешенное суммирование по головам и времени.

7.6. По типу данных / модальности

    Текстовые: word-level, subword-level, sentence-level, document-level attention.

    Визуальные: spatial attention, channel attention, temporal attention, branch attention.

    Мультимодальные: cross-modal attention (текст↔изображение, аудио↔текст).

    Графовые: node attention, edge attention, graph-level attention (GAT, GCN).

    Временные ряды: temporal attention, causal attention с lookahead.

7.7. По уровню применения

    Token-level — оценка на уровне отдельных токенов.

    Head-level — оценка на уровне голов внимания (head masking, head specialization).

    Layer-level — оценка на уровне слоёв (layer-wise attention analysis).

    Sequence-level — оценка на уровне целых последовательностей.

    Modality-level — оценка на уровне модальностей.

7.8. Специализированные и исследовательские методы

    Flow-Attention — введение flow conservation для избежания тривиального внимания.

    LASER Attention — экспоненциальное преобразование представлений перед attention для усиления градиентного сигнала.

    Kernel gradient descent attention — softmax self-attention как шаг градиентного спуска в ядерном пространстве.

    Max-margin token selection — градиентный спуск на attention-логитах сходится к max-margin решению.

    Noise-boosted activation functions — добавление шума в активации для улучшения attention-based visual processing.

    Selective attention mask — обучаемая маска, фильтрующая нерелевантные признаки (spatial, temporal, channel, semantic).

    Gated attention — attention с обучаемым гейтом для контроля пропуска информации.
  
   
  



**8.Выбор Mask**

Маска — это тензор (обычно булев или 0/1), который поэлементно управляет тем, какие данные модель «видит», какие игнорирует, какие обнуляет. Маски — это не один приём, а целое семейство техник, решающих разные задачи: от обработки батчей переменной длины до обучения BERT и подавления галлюцинаций в LLM.

Маска — говорит модели: «здесь не смотри», «здесь не считай loss», «здесь данные отсутствуют». Она применяется на трёх уровнях (вход, attention, loss) и в пяти ролях:

    padding — выравнивание батча,

    causal — авторегрессия,

    segment / modality — ограничение взаимодействий,

    loss — игнорирование позиций,

    random — само-супервизия.

Ключевые правила:

    True = «запрещено» — но проверяйте API.

    -1e9 безопаснее -inf.

    Комбинируйте маски через | (OR).

    Всегда маскируйте промпт в instruction tuning.

    Тестируйте на батче переменной длины.

В энкодерных архитектурах, например BERT, причинная маскировка не нужна: модель может использовать двунаправленное внимание.	

8.1. Зачем вообще нужны маски

Маски решают пять фундаментальных проблем:

    Переменная длина. В батче предложения разной длины. Чтобы сложить их в один тензор, короткие дополняются padding-токенами. Модель не должна учитывать эти токены.

    Причинность. В авторегрессионной генерации токен ii не должен видеть токены j>ij>i.

    Разные сегменты. В одной последовательности — вопрос и ответ, или две части диалога. Нужно ограничить attention между сегментами.

    Шум и пропуски. В данных есть пропущенные значения, выбросы, нерелевантные признаки — их нужно игнорировать в loss или в вычислениях.

    Само-супервизия. BERT маскирует 15% токенов, MAE — 75% патчей, чтобы модель училась восстанавливать.

Маски применяются на трёх уровнях:

    Вход — маскирование токенов/признаков,

    Внутри модели — attention-маски, dropout-маски, channel-маски,

    На выходе / в loss — игнорирование позиций при подсчёте ошибки.

8.2. Классификация масок по назначению
8.2.1. Padding mask (маска дополнения)

Самая базовая. В батче:


[The, cat, sat, on, mat]      → [The, cat, sat, on, mat, PAD, PAD]
[A, dog, barked]              → [A, dog, barked, PAD, PAD, PAD, PAD]

Padding-токены не должны влиять ни на attention, ни на loss.

Применение:

    Attention: позициям PAD присваивается −∞−∞ до softmax → вес 0.

    Loss: позиции PAD игнорируются (ignore_index).



8.2.2. Causal / look-ahead mask

Запрещает токену ii видеть позиции j>ij>i. Основа decoder-only Transformer (GPT, LLaMA).


[[0, -inf, -inf, -inf],
 [0,    0, -inf, -inf],
 [0,    0,    0, -inf],
 [0,    0,    0,    0]]


8.2.3. Combined mask (padding + causal)

В decoder-only моделях с батчем переменной длины нужно обе маски.


8.2.4. Segment / token-type mask

В BERT: token_type_ids разделяют две последовательности (вопрос / ответ). Attention разрешён только внутри сегмента или между сегментами — в зависимости от задачи.

В диалоговых моделях сегменты — это реплики. Маска ограничивает, кто кого «слышит».

8.2.5. Modality mask

В мультимодальных моделях (текст + изображение + аудио) маска определяет, какие модальности могут видеть друг друга.

    Full visual mask: визуальные токены видят друг друга полностью, текстовые — causal.

    Modality-mutual attention mask: «вырезание дыры» в causal-маске, чтобы image-токены могли attend к последующим текстовым.


8.2.6. Loss mask / ignore_index

При подсчёте CrossEntropy нужно игнорировать:

    padding-токены,

    промпт (при обучении на ответах),

    замаскированные токены в MLM.


8.2.7. Dropout mask

Стохастическая маска, обнуляющая нейроны с вероятностью pp:
python

mask = (torch.rand(x.shape) > p).float()
x = x * mask / (1 - p)  # inverted dropout — масштаб сохраняется

Внутри nn.Dropout это уже реализовано. Но иногда dropout применяют вручную — например, attention dropout (маскирование весов внимания) или DropPath (маскирование целых residual-веток).

8.2.8. Random mask (само-супервизия)

    BERT MLM: 15% токенов заменяются на [MASK], модель предсказывает их.

    MAE (Masked Autoencoders): 75% патчей изображения маскируются, модель восстанавливает.

    SimMIM, BEiT, Data2Vec: аналогично для изображений и речи.


8.2.9. ROI / spatial mask (изображения)

    ROI Align / RoI Pooling: маска выделяет область интереса.

    Instance segmentation: бинарная маска на каждый объект.

    Attention в ViT: spatial mask ограничивает attention по регионам.

    Inpainting: маска дефектов, которые нужно восстановить.



8.2.10. Channel mask

В аудио и многоканальных данных: маска на каналы (частоты, микрофоны). В TasNet / Conv-TasNet для разделения источников — маска на time-frequency представление.

8.2.11. Gradient mask

В обучении с подкреплением и multi-task: маскирование градиентов для отдельных параметров или задач.


8.2.12. Sparse / structured mask

В разреженных моделях (MoE, sparse attention) — маска маршрутизации: какие эксперты или какие блоки активируются для данного токена.


8.3. Техника применения: три способа
8.3.1. Additive mask (−∞−∞)

Классика для attention. К скорам добавляется матрица с 00 и −∞−∞. После softmax −∞−∞ превращается в 0.

8.3.2. Boolean mask (masked_fill)

Плюс: читаемо, эффективно.
Минус: нужно следить за типом (bool vs uint8).

8.3.3. Multiplicative mask (0/1)

Применяется к активациям, эмбеддингам, спектрограммам.

8.3.4. Index-based mask

Когда маска задаётся индексами, а не тензором.

Эффективнее по памяти, но менее удобно для батчей.

8.4. Маски в разных архитектурах

8.4.1. Transformer (encoder)

    Padding mask — обязательно.

    Attention mask — опционально (если нужно ограничить).

    Нет causal-маски (encoder bidirectional).



8.4.2. Transformer (decoder)

    Causal mask — обязательно.

    Padding mask — для входа и для памяти encoder.

    Cross-attention mask — padding маски для encoder-выхода.



8.4.3. Decoder-only (GPT, LLaMA)

    Combined causal + padding mask — обязательно.

    В inference — только causal, потому что батч = 1 (или padding выравнен).



8.4.4. Encoder-decoder (T5, BART)

    Encoder: padding.

    Decoder: causal + padding.

    Cross-attention: padding маски для encoder-выхода.

8.4.5. RNN / LSTM

    Packing — вместо маски: pack_padded_sequence физически убирает padding.

    Masked loss — обязательно, потому что RNN обрабатывает padding.


8.4.6. CNN

    Masked pooling — max/avg только по валидным позициям.

    Masked conv — свёртка с учётом маски (для inpainting, partial convolutions).



8.4.7. GNN

    Node mask — какие узлы учитывать.

    Edge mask — какие рёбра.

    Graph mask — какие графы в батче.

8.7. Лучшие практики

    Всегда проверяйте, что маска применяется на правильной оси. Визуализируйте mask[0] как heatmap.

    Используйте ignore_index=-100 — стандарт PyTorch.

    Комбинируйте padding + causal в decoder-only моделях.

    Не используйте -inf без необходимости — -1e9 безопаснее.

    Тестируйте на батче с разной длиной — баг с маской часто проявляется только там.

    Документируйте семантику маски — True = «запрещено» или «разрешено»? В разных API по-разному.

    Для inference без батча — causal-маска не нужна, is_causal=True достаточно.

    В RNN — packing, а не маска, если возможно.

    Проверяйте, что loss не считается по padding — иначе градиенты «размазываются».

    Логируйте долю замаскированных токенов — если 90% замаскировано, что-то не так.


**9.Softmax**

Softmax нормирует оценки внимания так, чтобы все значения были больше нуля, а сумма по каждой строке равнялась единице.
Softmax подходит для взаимоисключающих классов (один правильный класс). Для multi-label задач обычно используют независимые сигмоиды.
На практике часто используют численно устойчивую версию (вычитание максимума перед экспонентой).
В современных фреймворках Softmax часто «вшит» внутрь CrossEntropyLoss / F.cross_entropy для стабильности.

Основные способы использования Softmax в машинном обучении:

9.1. Многоклассовая классификация 

В выходном слое нейронных сетей (MLP, CNN, RNN, Transformer и т.д.).
Преобразует логиты (сырые оценки) в вероятностное распределение по классам (сумма = 1).
Используется вместе с функцией потерь Cross-Entropy (часто Softmax + CE объединяют в один численно устойчивый слой).
Применяется в:
Softmax Regression / Multinomial Logistic Regression
Классификации изображений, текста, речи
Языковых моделях (предсказание следующего токена)


9.2. Механизмы внимания (Attention)

В Transformers (self-attention, cross-attention) Softmax нормализует оценки внимания (attention scores), превращая их в веса, сумма которых равна 1.
Позволяет модели «фокусироваться» на наиболее релевантных частях последовательности.
Также встречается в soft-attention в других архитектурах.

9.3. Обучение с подкреплением (Reinforcement Learning)

Параметризация стохастической политики (Softmax policy / Boltzmann exploration).
Преобразует Q-значения или предпочтения действий в вероятности выбора действия.
Контролирует баланс exploration/exploitation через параметр температуры.
Используется в Policy Gradient, Actor-Critic и других методах.

9.4. Контрастивное обучение и losses

InfoNCE loss и похожие (SimCLR, CLIP и др.) — Softmax появляется в знаменателе при нормализации сходств.
Другие losses, где нужно получить распределение по «положительным» и «отрицательным» примерам.

9.5. Температурное масштабирование (Temperature Scaling)

Softmax с температурой.
Используется для:
Калибровки вероятностей модели
Knowledge Distillation (смягчение распределений учителя)
Управления «остротой» распределения (более/менее уверенные предсказания)


9.6. Иерархический Softmax (Hierarchical Softmax)

Эффективный вариант для очень больших словарей (например, в Word2Vec).
Заменяет полный Softmax деревом, снижая вычислительную сложность.

9.7. Gumbel-Softmax / Concrete Distribution

Дифференцируемая аппроксимация дискретного сэмплирования из категориального распределения.
Позволяет использовать градиентный спуск при работе с дискретными переменными (например, в VAE, дискретных латентных пространствах).

9.8. Другие применения

Нормализация в некоторых слоях/модулях (хотя реже, чем LayerNorm/BatchNorm).
Ensemble / усреднение моделей — Softmax-вероятности удобно усреднять.
Recommendation systems — предсказание вероятности выбора элемента.
Многоклассовый LDA, Naive Bayes и другие классические модели, где нужна вероятностная нормализация.
Softmax Bellman operator в RL (смягчённый оператор Беллмана).



**10. Feed-Forward Network (FFN)**

FFN обрабатывает выходы механизма внимания. В классическом трансформере он состоит из двух линейных слоёв и нелинейности между ними, обычно ReLU. В современных LLM часто используются GeGLU, SwiGLU и другие варианты. Первый линейный слой обычно расширяет размерность, второй возвращает её к emb_size.
FFN — это одновременно и самая базовая архитектура нейронных сетей, и один из самых критически важных строительных блоков больших моделей.

10.1. Классические полносвязные нейронные сети (MLP / FFN)

Самостоятельные модели для классификации и регрессии (особенно на табличных данных).
Аппроксимация произвольных непрерывных функций (Universal Approximation Theorem).
Задачи: кредитный скоринг, медицинская диагностика, прогнозирование оттока клиентов, обнаружение мошенничества, прогнозирование временных рядов (без явной последовательности).

10.2. Ключевой компонент Transformer-архитектур

Position-wise FFN (или MLP-блок) в каждом слое Transformer (после Attention).
Структура: линейный слой (расширение размерности) → нелинейность (ReLU / GELU / SwiGLU) → линейный слой (сжатие обратно).
Роли:
Вносит нелинейность.
Хранит большую часть «знаний» модели (факты, паттерны, ассоциации).
Восстанавливает изотропию эмбеддингов токенов.
Занимает 50–70 % всех параметров современных LLM.

Применяется в: GPT, BERT, LLaMA, T5, Vision Transformer (ViT), любых encoder/decoder Transformer-ах.

10.3. Mixture-of-Experts (MoE)

FFN заменяется набором «экспертов» (нескольких FFN).
Router выбирает 1–2 эксперта на каждый токен.
Позволяет масштабировать параметры модели (до триллионов) при почти неизменной вычислительной стоимости.
Используется в Mixtral, Switch Transformer, DeepSeek-MoE и др.

10.4. Компонент более сложных архитектур

В конце CNN: полносвязные слои после свёрточных (классический ImageNet-подход).
В Autoencoder / VAE: энкодер и декодер часто строятся из FFN.
В GAN: генератор и дискриминатор (особенно ранние версии).
В рекомендательных системах: Wide & Deep, DeepFM и другие модели ранжирования.
В Reinforcement Learning: аппроксиматоры value-функции и политики (DQN, Actor-Critic, PPO и т.д.).

10.5. Специализированные и научные применения

Physics-Informed Neural Networks (PINNs) — решение дифференциальных уравнений.
Feature transformation / embedding layers в гибридных моделях.
Knowledge editing и fine-tuning (многие методы, такие как ROME / MEMIT, нацелены именно на веса FFN).
Условные FFN (с модуляцией от внешних условий — timestep, class label и т.д.).

10.6. Оптимизации и варианты FFN

Pruning / sparsification FFN.
Low-rank и structured FFN (для ускорения).
Fast Feed-Forward Networks (логарифмическая сложность).
Разные активации: ReLU → GELU → SwiGLU / GeGLU (современный стандарт).
Параллельная схема Attention + FFN (как в PaLM).


**11.Layer Normalization**

Слои нормализации стабилизируют обучение, нормализуя активации между слоями. Они не добавляют нелинейность — нелинейность добавляют функции активации. LayerNorm приводит нормализуемые значения к нулевому среднему и единичной дисперсии. RMSNorm не центрирует среднее.

11.1. Transformer-архитектуры (самое важное современное применение)

Стандартный компонент в каждом блоке Transformer (после Attention и после FFN).
Два основных варианта размещения:
Post-LN (оригинальный Transformer 2017) — нормализация после residual-соединения.
Pre-LN (современный стандарт в GPT, LLaMA, PaLM и др.) — нормализация перед Attention/FFN.

Стабилизирует обучение, улучшает градиентный поток, предотвращает взрыв/затухание активаций.
Используется практически во всех LLM и Vision Transformer (ViT).

11.2. Рекуррентные нейронные сети (RNN / LSTM / GRU)

Оригинальное применение LayerNorm (статья Ba et al., 2016).
Нормализует скрытые состояния на каждом временном шаге независимо.
Стабилизирует динамику скрытых состояний на длинных последовательностях и снижает проблему vanishing/exploding gradients.

11.3. Feed-Forward Networks (MLP)

Применяется в полносвязных сетях, особенно при маленьком размере батча или онлайн-обучении.
Делает обучение менее чувствительным к инициализации и гиперпараметрам.

11.4. Свёрточные сети (CNN) и Vision-модели

В классических CNN BatchNorm обычно лучше, но LayerNorm используется:
в современных архитектурах, вдохновлённых Transformer (ConvNeXt);
в Vision Transformer;
при маленьких батчах;
в Adaptive LayerNorm (adaLN) — параметры γ и β зависят от внешних условий (класс, timestep и т.д.).


11.5. Генеративные модели

Diffusion Transformers (DiT) — часто с Adaptive LayerNorm (adaLN / adaLN-Zero).
Некоторые GAN и автоэнкодеры.
Стабилизация обучения генераторов и дискриминаторов.

11.6. Reinforcement Learning

В агентах с последовательными наблюдениями и переменным размером батча.
Помогает стабилизировать обучение политик и value-функций при разреженных наградах.

11.7. Federated Learning и распределённое обучение

Не зависит от статистики батча → устойчив к неоднородным распределениям данных между клиентами.
Предотвращает feature norm collapse и переобучение на локальных данных.

11.8. Fine-tuning и Parameter-Efficient методы

Тонкая настройка только параметров LayerNorm (γ и β) часто даёт сильный эффект при минимальном количестве обучаемых параметров.
Используется в continual learning, multi-modal adaptation и domain adaptation.

11.9. Другие специальные случаи

Online learning — работает даже при batch size = 1.
Нормализация перед классификатором (last-layer LN) для улучшения обобщения.
В комбинации с residual-соединениями для контроля масштаба градиентов.
Adaptive LayerNorm (adaLN) — γ и β вычисляются из внешнего conditioning-сигнала.

**12. Остаточные связи Residual Connections**

Остаточные связи помогают бороться с исчезающими градиентами и облегчают обучение. Основная часть параметров и знаний современных LLM хранится в FFN, а не в остаточных связях.

12.1. Классические Residual Networks (ResNet) в Computer Vision

Основное применение — глубокие свёрточные сети (ResNet-18/50/101/152 и глубже).
Каждый residual-блок обучает остаточную функцию $F(x)$, а выход блока = $F(x) + x$.
Позволяет обучать сети с сотнями и тысячами слоёв, решая проблему деградации (degradation problem) и затухающих градиентов.
Используется как backbone в:
классификации изображений
детекции объектов (Faster R-CNN, RetinaNet, YOLO и др.)
семантической сегментации
медицинских изображениях, автономном вождении и т.д.


12.2. Transformer-архитектуры (обязательный компонент)

В каждом блоке Transformer residual-связи стоят вокруг:
Multi-Head Attention
Feed-Forward Network (FFN)

Формула: $x + \text{Sublayer}(x)$ (часто в сочетании с LayerNorm — Pre-LN или Post-LN).
Без residual-связей очень глубокие Transformer’ы (десятки–сотни слоёв) практически невозможно обучить.
Присутствуют во всех современных LLM (GPT, LLaMA, BERT, T5 и др.) и Vision Transformer (ViT).

12.3. U-Net и encoder-decoder архитектуры

Skip-connections между encoder и decoder (обычно конкатенация, а не сложение).
Передают высокодетализированные feature maps из ранних слоёв в поздние.
Критически важны для сегментации, медицинской визуализации, image-to-image translation.

12.4. Рекуррентные сети и последовательности

Residual-связи внутри LSTM/GRU или между временными шагами.
LSTM по своей природе уже содержит residual-подобную связь через cell state.
Используются в глубоких RNN для стабилизации обучения на длинных последовательностях.

12.5. Graph Neural Networks (GNN)

Residual-связи предотвращают oversmoothing (когда эмбеддинги узлов становятся слишком похожими).
Позволяют строить более глубокие GNN.

12.6. Генеративные модели

GAN (особенно глубокие генераторы и дискриминаторы).
VAE, Diffusion Models, Masked Autoencoders (MAE).
Улучшают стабильность обучения и качество генерации.

12.7. Reinforcement Learning

В deep Q-networks (DQN), Actor-Critic, policy networks.
Используются в системах типа AlphaGo Zero, AlphaStar, AlphaFold.

12.8. Другие архитектуры и варианты

DenseNet — extreme-версия (каждая слой соединяется со всеми предыдущими через конкатенацию).
Highway Networks — gated residual-связи (обучаемые гейты).
Scaled / Weighted Residuals — умножение residual-ветки на коэффициент (фиксированный или обучаемый).
Parallel Residuals и multi-stream residual streams.
Pre-activation residual blocks (BatchNorm/Activation перед свёрткой).
Residual connections в speech recognition, time-series, recommendation systems и т.д.


**13. Слои**

Блоки декодера называются слоями. Их количество — параметр модели. Слои идут последовательно, и каждый блок захватывает дополнительный контекст. Сначала это низкоуровневый контекст, затем контекст для контекста и т.д. Это позволяет трансформерам строить высокоуровневые представления входных данных.
Слои комбинируются в сложные архитектуры (ResNet, Transformer, U-Net, EfficientNet и т.д.), и именно правильный выбор и порядок слоёв определяет возможности модели.

Основной компонент для построения нейронной сети — это слой, и классы для их создания.

Глубокие нейронные сети строятся из нескольких слоёв. Каждый слой имеет два основных компонента:

    Трансформация (код)

    Набор весов (данные)

Когда мы передаём тензор в сеть, он проходит через каждый слой, пока не достигнет выхода. Этот процесс называется прямым проходом. Каждый слой имеет свою трансформацию, и тензор проходит через каждый слой. Композиция всех трансформаций слоёв определяет общую трансформацию сети. Цель — преобразовать входные данные в правильный класс, и в процессе обучения веса слоёв обновляются, чтобы улучшить предсказания.

    Расширьте базовый класс.

    Определите слои как атрибуты класса.

    Реализуйте метод прямого прохода.

Более детальная версия:

    Создайте класс нейронной сети, который расширяет базовый класс.

    В конструкторе класса определите слои сети как атрибуты класса, используя предопределённые слои.

    Используйте атрибуты слоёв сети для определения прямого прохода сети.

В каждом слое есть два основных элемента: функция прямого прохода и тензор весов. Тензор весов содержит значения, которые обновляются в процессе обучения сети, поэтому мы указываем наши слои как атрибуты класса. Класс отслеживает тензоры весов внутри каждого слоя. Код, который выполняет это отслеживание, находится внутри класса, и поскольку мы расширяем этот класс, мы автоматически наследуем эту функциональность.

Нужно назначить наши слои как атрибуты внутри нашего модуля сети, и базовый класс зарегистрирует веса как обучаемые параметры нашей сети.

Параметр против аргумента

Параметры используются в определениях функций как заполнители, в то время как аргументы — это фактические значения, которые передаются функции. Параметры можно рассматривать как локальные переменные, которые существуют внутри функции. В случае нашей сети имена являются параметрами, а значения, которые мы указали, — это аргументы.
Два типа параметров

    Гиперпараметры.

    Зависимые от данных гиперпараметры.

Когда мы создаём слой, мы передаём значения для каждого параметра в конструктор слоя.

Гиперпараметры

Это параметры, значения которых выбираются вручную и произвольно.

13.1. Базовые структурные слои

Input Layer Принимает сырые данные

Hidden Layers Извлекают признаки и преобразуют данные

Output Layer Формирует итоговый прогноз 

13.2. Полносвязные слои (Dense / Fully Connected / Linear)

Каждый нейрон соединён со всеми нейронами предыдущего слоя.
Применение: классификация и регрессия на табличных данных, финальные головы моделей (classifier head), MLP, FFN в Transformer’ах.

13.3. Свёрточные слои (Convolutional Layers)

Применяют фильтры (kernels) для извлечения локальных пространственных признаков.
Применение: компьютерное зрение (CNN), обработка изображений, видео, аудио, иногда текста и временных рядов.

13.4. Пулинг-слои (Pooling Layers)

Уменьшают размерность feature maps (MaxPool, AvgPool, Global Pooling).
Применение: снижение вычислительной сложности, повышение инвариантности к сдвигам в CNN.

13.5. Рекуррентные слои (RNN, LSTM, GRU)

Имеют память (скрытое состояние) и обрабатывают последовательности.
Применение: обработка текста, речи, временных рядов, машинный перевод (до эпохи Transformer).

13.6. Attention / Self-Attention слои

Вычисляют взвешенные взаимодействия между элементами последовательности.
Применение: Transformer, BERT, GPT, Vision Transformer, современные NLP и multimodal-модели.

13.7. Нормализационные слои

BatchNorm — нормализация по батчу (особенно в CNN).
LayerNorm — нормализация по признакам одного примера (стандарт в Transformer).
GroupNorm / InstanceNorm — альтернативы при маленьком батче или специфических задачах.
Применение: стабилизация обучения, ускорение сходимости, улучшение обобщения.

13.8. Регуляризационные слои

Dropout — случайно обнуляет нейроны во время обучения.
DropPath / Stochastic Depth — отключает целые блоки.
Применение: борьба с переобучением.

13.9. Активационные слои (Activation)

Вводят нелинейность: ReLU, GELU, Swish, Sigmoid, Tanh, Softmax и др.
Применение: практически во всех слоях после линейных/свёрточных преобразований.

13.10. Embedding-слои

Преобразуют дискретные токены / категории в плотные векторы.
Применение: NLP (word/token embeddings), рекомендательные системы, категориальные признаки.

13.11. Остаточные и skip-соединения (Residual / Skip Connections)

Добавляют вход блока к его выходу ($x + F(x)$).
Применение: ResNet, Transformer, U-Net, глубокие сети любого типа — для борьбы с затуханием градиентов.

13.12. Специализированные и вспомогательные слои

Flatten / Reshape / Permute — изменение формы тензора.
Concatenation / Addition — объединение признаков.
Upsampling / Transposed Convolution — увеличение разрешения (сегментация, генерация).
Positional Encoding — добавление информации о позиции (Transformer).
Gating layers (в LSTM, Highway Networks, GLU).
Mixture-of-Experts (MoE) — разреженные слои с маршрутизацией.

13.13. Выходные / task-specific слои

Softmax — многоклассовая классификация.

Sigmoid — бинарная / multi-label классификация.
Linear — регрессия.

Специализированные головы: detection head, segmentation head, generation head и т.д.

Краткая сводка по областям применения

Табличные данные → Dense + Normalization + Dropout

Изображения → Conv + Pooling + BatchNorm + Residual

Последовательности / Текст → Embedding + Attention / RNN + LayerNorm + Residual

Генерация → те же слои + Upsampling / Transposed Conv

Мультимодальные модели → комбинация всех вышеперечисленных


**14.Вероятностное сэмплирование**

Жадная выборка (greedy search) — это выбор токена с максимальной вероятностью. У неё есть недостатки: модель может зацикливаться и выдавать повторяющиеся фрагменты, а текст получается шаблонным.

Чтобы добавить разнообразие, используют вероятностное сэмплирование (Multinomial sampling). При нём токен выбирается случайно, но с учётом распределения вероятностей. Чем выше вероятность токена, тем выше шанс, что он будет выбран. Даже у маловероятного токена остаётся шанс. Текст получается менее шаблонным, но возрастает риск галлюцинаций. Для этого уже есть вероятности каждого токена — нужно только выбрать токен согласно распределению.

Вероятностное сэмплирование (Probabilistic Sampling) в машинном обучении — это широкий класс методов, при которых мы генерируем случайные выборки из вероятностных распределений. Оно используется почти во всех областях ML: от обучения моделей и генерации данных до байесовского вывода и принятия решений.
Разберём подробно основные применения и техники.

14.1. Сэмплирование данных для обучения (Data Sampling)

Цель: получить репрезентативную или сбалансированную подвыборку из большого датасета.

Основные методы:

Простое случайное сэмплирование (Simple Random Sampling) — каждый пример выбирается с равной вероятностью.

Стратифицированное сэмплирование (Stratified Sampling) — сохраняет пропорции классов.

Взвешенное сэмплирование (Weighted / Importance Sampling) — вероятность выбора примера пропорциональна его весу (например, частоте класса или важности).

Bootstrap-сэмплирование — выборка с возвращением. Лежит в основе Random Forest, Bagging, оценки неопределённости.

Soft Random Sampling — на каждой эпохе берётся случайная подвыборка (эффективно для огромных датасетов).

14.2. Сэмплирование из распределений (Sampling from Probability Distributions)

Это ядро вероятностного ML. Используется, когда нужно получить реализацию случайной величины.

Базовые методы:

Inverse Transform Sampling — через обратную функцию распределения (для простых распределений).
Rejection Sampling (выборка с отклонением) — генерируем из простого предложения и принимаем/отклоняем с вероятностью.

Importance Sampling — сэмплируем, а потом перевзвешиваем с весами. Часто используется в вариационном выводе и оценке ожиданий.

Продвинутые методы :

Markov Chain Monte Carlo (MCMC):
Metropolis-Hastings
Gibbs Sampling
Hamiltonian Monte Carlo (HMC) / NUTS (используется в Stan, Pyro, NumPyro)

Variational Inference + reparameterization trick (в VAE, Bayesian Neural Networks).

 
14.3. Сэмплирование в генеративных моделях

VAE / Normalizing Flows / Diffusion Models — сэмплирование из латентного пространства или через процесс шумоподавления.
Autoregressive модели (GPT и др.) — сэмплирование следующего токена:
Greedy
Temperature sampling
Top-k sampling
Nucleus (Top-p) sampling
Beam search (не чисто вероятностный)


14.4. Байесовский вывод и неопределённость

Сэмплирование из апостериорного распределения с помощью MCMC или variational methods.

Используется для:

Bayesian Neural Networks
Оценки неопределённости (epistemic uncertainty)
Bayesian Optimization
Gaussian Processes


Практические рекомендации

Нужно просто случайно взять подвыборку данных → Random / Stratified / Weighted Sampling
Нужно оценить интеграл / ожидание → Monte Carlo / Importance Sampling
Распределение сложное (апостериорное) → MCMC или Variational Inference
Генерация текста / действий → Categorical / Temperature / Top-p sampling
Генерация изображений → Diffusion sampling methods



**15.KV-cache**

KV-cache кэширует Key и Value предыдущих токенов, чтобы при авторегрессионной генерации не пересчитывать их заново. Это ускоряет инференс, но увеличивает потребление памяти.


**16. Нормализация**

Помогает стабилизировать градиенты, ускоряет сходимость и улучшает обобщение. В декодере обычно две остаточные связи: вокруг внимания и вокруг FFN.

Нормализация в ML делится на два больших класса:

Нормализация данных (Feature Scaling / Data Normalization) — предобработка входных признаков.

Нормализация внутри нейронных сетей (Activation / Weight Normalization) — слои, которые нормализуют активации или веса во время обучения.


**17.Авторегрессия**


Авторегрессия (AR) — это принцип, при котором значение в текущий момент предсказывается на основе предыдущих значений той же последовательности. Ниже перечислены все ключевые применения.
17.1. Классическое прогнозирование временных рядов

AR(p) — простая авторегрессионная модель порядка $p$.
ARMA / ARIMA / SARIMA — с добавлением скользящего среднего, дифференцирования и сезонности.
VAR (Vector Autoregression) — многомерные временные ряды (несколько взаимосвязанных рядов).
Применение: прогноз цен акций, спроса, погоды, трафика, энергопотребления, экономических показателей.

17.2. Языковые модели и генерация текста

Все современные LLM (GPT, LLaMA, Claude, Gemini и т.д.) — это авторегрессионные модели.
Используется при:
генерации текста
ответе на вопросы
суммаризации
написании кода
машинном переводе (в decoder-only и encoder-decoder архитектурах)


17.3. Генерация изображений

PixelRNN / PixelCNN — предсказывают следующий пиксель на основе предыдущих (слева направо, сверху вниз).
Современные авторегрессионные image-модели (например, на основе Transformer или VQ-VAE + AR).
Image inpainting, супер-разрешение, генерация изображений по частям.

17.4. Генерация аудио и речи

WaveNet, WaveRNN и подобные модели генерируют звук сэмпл за сэмплом.
Современные speech synthesis и music generation модели часто используют авторегрессионный подход (или гибриды с diffusion).

17.5. Генерация видео

Видео рассматривается как последовательность кадров (или токенов).
Каждый следующий кадр/токен генерируется условно от предыдущих.

17.6. Глубокое обучение на последовательностях

Autoregressive Neural Networks (ARNN) — нейросети, которые явно используют лаговые значения как признаки.
DeepAR (Amazon) — вероятностное прогнозирование временных рядов с помощью RNN + авторегрессии.
Гибриды: AR + LSTM, AR + Transformer, Neural ARIMA и т.д.

17.7. Специальные варианты и расширения

Teacher Forcing — при обучении авторегрессионных моделей (подстановка правильных предыдущих токенов).
Scheduled Sampling — постепенный переход от teacher forcing к собственному предсказанию.
Non-autoregressive модели (для сравнения) — генерируют всё сразу, но обычно уступают в качестве.
Autoregressive flows и Autoregressive Density Estimation.


**18.Весовые коэффициенты**

Весовые коэффициенты (веса) — это числовые параметры модели, которые определяют силу влияния входных данных на выход. Ниже перечислены все ключевые способы их использования.

18.1. Основные параметры нейронных сетей

Связи между нейронами. Каждый вес показывает, насколько сильно сигнал от нейрона 1 влияет на нейрон 2.
Хранилище «знаний» модели — именно в весах закодированы все выученные закономерности.
Применяются во всех типах слоёв: Dense, Convolutional, Recurrent, Attention и т.д.

18.2. Инициализация весов (Weight Initialization)

Случайная инициализация (Normal, Uniform)
Xavier / Glorot Initialization
He Initialization (для ReLU)
LeCun Initialization
Orthogonal, Sparse и другие современные методыЦель: обеспечить стабильный старт обучения и избежать vanishing/exploding gradients.

18.3. Обучение и оптимизация весов

Обновление с помощью градиентного спуска и его вариантов (SGD, Adam, AdamW, Lion и др.)
Backpropagation — вычисление градиентов по весам
Weight Decay (L2-регуляризация) — штрафует большие веса
L1-регуляризация — способствует разреженности весов

18.4. Регуляризация через веса

Weight Decay / L2 Regularization — ограничение величины весов
Weight Constraints (MaxNorm, UnitNorm, MinMaxNorm) — жёсткое ограничение нормы весов
Spectral Normalization — ограничение спектральной нормы (особенно в GAN)
Weight Standardization — нормализация весов свёрточных фильтров

18.5. Веса в классических алгоритмах ML

Линейная и логистическая регрессия — коэффициенты регрессии
SVM — веса опорных векторов
Взвешенные методы (Weighted KNN, Weighted Least Squares)
Ансамбли (взвешенное голосование в Boosting, Stacking)

18.6. Веса в Attention и Transformer

Query, Key, Value проекции — матрицы весов
Attention scores → Softmax → attention weights
Output projection weights

18.7 Другие важные применения

Pruning — обнуление малозначимых весов (сжатие моделей)
Quantization — уменьшение разрядности весов (INT8, INT4)
Knowledge Distillation — перенос знаний через веса
Transfer Learning / Fine-tuning — дообучение предобученных весов
LoRA / QLoRA / Adapters — обучение низкоранговых добавок к весам
Weight Averaging (SWA, EMA) — усреднение весов для улучшения обобщения
Ensemble of weights (Snapshot Ensembles, Polyak averaging)



**19.Обучаемые параметры**

Обучаемые параметры - это параметры, значения которых оптимизируются в процессе обучения.
Мы начинаем с произвольных значений, которые обновляются по мере обучения сети, чтобы минимизировать функцию потерь.
Эти обучаемые параметры - это веса внутри нашей сети, находящиеся в каждом слое.
