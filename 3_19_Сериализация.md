Сериализация — текстовый checkpoint: метаданные (architecture, device, dtype, mode, lr, gamma) и блоки [[layer]] с shape, весами и bias. save пишет всё через write_dense_layer; load находит секции по имени и подставляет матрицы в уже созданную сеть той же топологии. Формат простой, отлаживаемый и не зависит от внешних crate форматов вроде pickle или LibTorch.

Модель сохраняется в читаемый текстовый файл (расширение вроде .model), без serde и без бинарного формата. Это учебный checkpoint: метаданные + веса всех Dense-слоёв.

1. Зачем свой формат

Не тянуть LibTorch / pickle чистый std::fs + текст

Можно открыть в редакторе human-readable

Восстановить веса после обучения save / load

Ошибки I/O AppError::Io / SerializationError

2. API


```
pub fn save(&self, path: &str) -> Result<(), AppError>
pub fn load(&mut self, path: &str) -> Result<(), AppError>
```


Типичное использование:

```
nn.save("cat_model.model")?;
let mut nn2 = CatPolicyNetwork::from_config(same_config);
nn2.load("cat_model.model")?;
```

load мутирует уже созданную сеть (слои должны совпадать по размерам с архитектурой).

3. Что пишет save

Шаг 1 — файл и заголовок

```
let mut f = File::create(path).map_err(AppError::Io)?;
writeln!(f, "# CatPolicyNetwork model file")?;

```

Шаг 2 — метаданные

architecture: SimpleMLP

device: Cpu

dtype: Float16

mode: Train

base_lr: 0.008

gamma: 0.99

Архитектура, устройство, тип данных, режим Train/Eval и ключевые hyperparams.

Шаг 3 — каждый Dense-слой

Вызовы:
```
write_dense_layer(..., "layer1", &self.layer1)
write_dense_layer(..., "layer_hidden_0", ...)  // если есть
write_dense_layer(..., "layer2_policy", ...)
write_dense_layer(..., "layer_value", ...)

```


4. Формат одного слоя: write_dense_layer

```
fn write_dense_layer(&self, f: &mut File, name: &str, layer: &DenseLayer)

```
Структура блока:

[[layer1]]

shape: 8 1

0.05 0.1 0.15 ...     ← строка весов (out × in), по одной строке на 

нейрон выхода

...

0.0                    ← bias, по одному на строку

0.0

...


5. Как работает load

File::open → все строки в Vec<String> (ошибка I/O → AppError::Io).

Пустой файл → SerializationError.

Цикл по строкам:

ищем [[...]];

читаем shape: out in;

читаем out строк весов и out bias;

по имени секции кладём в нужный слой:



```
match name {
    "layer1" => { self.layer1.weights = ...; self.layer1.bias = ...; }
    "layer2_policy" => { ... }
    "layer_value" => { ... }
    n if n.starts_with("layer_hidden_") => {
        // индекс из имени → self.layer_hidden[hi]
    }
    _ => {}
}
```

Метаданные (architecture, device, …) при load не перезаписывают поля структуры автоматически (в текущей версии парсятся в основном веса). Сеть должна быть создана с той же архитектурой, иначе размеры layer_hidden могут не совпасть — лишние секции игнорируются, недостающие не создаются.

6. Обработка ошибок

Нет прав / путь неверный AppError::Io
 
Пустой файл AppError::SerializationError

Сбой write!/writeln!AppError::Io через map_err

Битая строка веса parse → unwrap_or / skip (мягко)

Нет panic! на типичном пути save/load.
