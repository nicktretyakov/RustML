Размеры 6000 файлов на облачном диске в files (МБ) имеют правостороннюю асимметрию: много документов и несколько видео. Программа считывает размер выборки; в заготовке есть sample_means и две диаграммы.

    Получите 500 выборочных средних для выборки такого размера.
    Выведите разность среднего и медианы для файлов, затем для средних (2 знака после запятой).
    Постройте гистограмму файлов на axs[0], а средних — на axs[1], задайте bins=12 и покажите графики.
