# **Алгоритмы операций над тензорами**

В проекте реализована мини-тензорная библиотека в духе tch-rs / Burn: структура Tensor + поэлементные операции, редукции, приведение типа и использование в DenseLayer. Всё на чистом Rust (Vec<f32>), без LibTorch.

Операции над тензорами — это 1D-Tensor с поэлементными add/sub/mul/div, скалярными scalar_mul/add, редукциями sum/mean/max/min, cast через to_dtype и отдельным mat_vec_mul для Dense. Размерности проверяются через Result, dtype результата наследуется от левого операнда, а в сети эти алгоритмы связывают linear layer, bias и scaling градиента REINFORCE.


1. Структура Tensor


```
pub struct Tensor {
    pub data: Vec<f32>,  // значения (физически всегда f32)
    pub dtype: DType,    // семантика точности: Float32 / Float16 / Int8
}
```

Это не многомерный тензор с shape/strides, а 1D-вектор + dtype — достаточно для state, bias, градиентов policy.

new(data, dtype) cast_vec под dtype, затем сохранение

from_slice(slice, dtype) из &[f32] 

zeros(len, dtype) / ones(...) заполнение 0 или 1 с cast 

to_vec() копия data

len() / is_empty() размер

При любом new данные сразу проходят через dtype.cast_vec (симуляция half/int8).

2. Элементные операции (element-wise)

Общий алгоритм для add / sub / mul / div:

Проверить self.len() == other.len(), иначе AppError::DimensionMismatch.

zip по парам элементов → операция.

Собрать Vec<f32> → Tensor::new(result, self.dtype) (снова cast под dtype результата).

Сложение / вычитание / умножение

// add:  result[i] = a[i] + b[i]
// sub:  result[i] = a[i] - b[i]
// mul:  result[i] = a[i] * b[i]   // Hadamard product, не matmul

Возвращают Result<Tensor, AppError>.

Деление

```
map(|(&a, &b)| if b == 0.0 { 0.0 } else { a / b })
```

Защита от деления на ноль: вместо inf/NaN подставляется 0.0

Скалярные операции

scalar_mul(s)  // x[i] * s

scalar_add(s)  // x[i] + s

Без проверки размерностей; возвращают Tensor напрямую (не Result).

scalar_mul используется в policy gradient: d_logits * advantage.


3. Редукции (свёртка вектора в скаляр)

sum() iter().sum()

mean() sum / len, для пустого → 0.0

max() max_by(partial_cmp), пустой → 0.0

min() аналогично

Это редукции по всему тензору, без оси (dim).

Не путать с Reduction в loss (Mean/Sum/None для REINFORCE) — там другой enum и другая задача.

4. Приведение типа

```
pub fn to_dtype(&self, target: DType) -> Tensor {
    if self.dtype == target {
        self.clone()
    } else {
        Tensor::new(self.data.clone(), target)  // внутри cast_vec
    }
}
```

Аналог .to(torch.float16) / .to_dtype() в Burn.

Правила огрубления — в DType::cast_value (F16 ≈ сетка $1/2048$, Int8 → round + clamp).

5. Матричное умножение (отдельно от Tensor)

```
pub fn mat_vec_mul(matrix: &[Vec<f32>], input: &[f32]) -> Result<Vec<f32>, AppError>

```

проверка input.len() == matrix[0].len();

двойной цикл по out × in;

результат — Vec<f32>, не Tensor (дальше его оборачивают в Tensor в DenseLayer).

Полноценного matmul двух матриц / broadcast нет — для MLP policy хватает W @ x.

6. Как операции используются в сети

В DenseLayer::forward:

input &[f32]

    → Tensor (Float32) → to_dtype(layer.dtype)     // cast
    
    → mat_vec_mul(weights, x)                      // линейный слой
    
    → Tensor(output) + Tensor(bias)                // add
    
    → при Int8: ещё раз cast_vec                   // quantize
    
В reinforce_step:

d_logits (probs - one_hot)

    → Tensor::from_slice(...).scalar_mul(advantage)  // масштаб градиента
    
То есть тензорные ops — не декорация, а реальный путь данных в forward/backward-упрощении.

7. Обработка ошибок

Разная длина в add/sub/mul/div Err(DimensionMismatch)

Пустой вход в DenseLayer::forward Err(EmptyTensor)

Несовпадение W и x в mat_vec_mul Err(DimensionMismatch)

div на 0 0.0 (без Err)

Пустой тензор в mean/max/min безопасный default

Бинарные element-wise операции — через Result; скалярные и редукции — без Result (проще API).

8. Схема семейств операций

Tensor

├── Construct: new, from_slice, zeros, ones

├── Element-wise (два тензора): add, sub, mul, div

├── Scalar: scalar_mul, scalar_add

├── Reduction: sum, mean, max, min

├── Cast: to_dtype

└── (вне Tensor) mat_vec_mul → основа Dense
