150 цветков ириса, каждый обозначен точкой в соответствии с размером его лепестков:

Модель может научиться их различать, а затем определять цветы, которых она никогда не видела.

Загрузка данных.


let mut rng = SmallRng::seed_from_u64(0);
let (train, test) = linfa_datasets::iris()
    .shuffle(&mut rng)          // перемешиваем
    .split_with_ratio(0.75);    // 75% → train, 25% → test

Построение индекса. K-D tree ускоряет поиск ближайших соседей с O(n·d) (полный перебор) до O(log n) в среднем:


let nn = CommonNearestNeighbour::KdTree
    .from_batch(&train_records, L2Dist)
    .unwrap();

L2Dist — стандартное евклидово расстояние.

KNN-классификация. Для каждого тестового объекта:

    находим k = 5 ближайших соседей в train;

    считаем голоса по классам;

    выбираем класс с максимумом голосов (при равенстве — меньший индекс класса).

Оценка и визуализация. Совпадение guesses[i] == test_targets[i] даёт верные предсказания; plotters рисует точки по 3-му и 4-му признакам (petal length, petal width) и крестики для ошибок.

Откройте PNG любым просмотрщиком изображений. На графике:

    Цветные кружки — правильные предсказания (цвет соответствует предположенному классу: синий = setosa, зелёный = versicolor, малиновый = virginica).

    Красные крестики — ошибки модели (обычно их 0–2).

Ожидаемый вывод


Studied 112 flowers
Named 37 of 38 new flowers correctly
Saved plot to iris_linfa.png

Почему 112 и 38? 150 × 0.75 = 112.5, split_with_ratio(0.75) отдаёт 112 в train и 38 в test. Точное число зависит от округления внутри Linfa — если увидите 113/37, это тоже нормально.

Точность ~97–100% (37–38 верных из 38) — это стандартный результат для KNN с k=5 на Iris. Ошибки, если и бывают, то всегда на границе versicolor↔virginica.
