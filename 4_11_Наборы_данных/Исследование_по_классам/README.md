По какому измерению клеток можно определить злокачественный образец? В load_breast_cancer класс 0 — злокачественный, а класс 1 — доброкачественный. В начальном коде некоторые названия признаков считываются в features.

    Для каждого признака выведите его среднее значение для злокачественных образцов, делённое на среднее значение для доброкачественных образцов, округлив результат до 2 знаков с помощью round.
    После цикла укажите признак с наибольшим отношением.

Для признаков worst radius и worst texture:
cargo run --release < input.txt
worst radius: malignant is 1.58 times benign
worst texture: malignant is 1.25 times benign
Best separator: worst radius
