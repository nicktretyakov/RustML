Модель обучается только на числовых столбцах, поэтому компания такси сначала проверяет журнал поездок. Программа загружает taxi_trips.csv в trips и считывает число n.

    Выведите Trips: и количество строк.
    Для каждого столбца по порядку выведите его имя, двоеточие и numbers, если метод .describe() включает его в сводку, иначе text.
    Выведите первые n строк.

Для таблицы с 30 арендованными велосипедами и n = 2:

Trips: 30
bike: text
km: numbers
station: text
   bike    km  station
0  B-12   4.6     Pier
1  B-07  11.2  Central
