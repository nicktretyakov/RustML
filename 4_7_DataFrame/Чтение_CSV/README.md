Кофейня сохраняет по одному CSV-файлу на каждый день: monday.csv, tuesday.csv и так далее. В каждом файле есть столбцы drink и cups. Программа считывает название дня в нижнем регистре в переменную day.

Сформируй имя файла для этого дня, загрузи файл в DataFrame orders и выведи его.

Если бы днём недели было sunday, а в файле sunday.csv содержались строки drink,cups, mocha,5 и chai,13, ты бы увидел:

   drink  cups
0  mocha     5
1   chai    13
